# Campus №1 — общий проект

Дата состояния: 9 октября 2026 года. Приложение: V13.10. Установщик: V13.10.1.

Telegram-бот, Apps Script API и Telegram Mini App относятся к одному проекту Campus №1.
Основные рабочие исходники находятся у пользователя: `C:\tg` (бот и API),
`C:\campus1-miniapp` (интерфейс, существующий Git-репозиторий, ветка `main`).
Пути могут быть изменены через CAMPUS_GAS_PATH и CAMPUS_FRONT_PATH.
Новый проект или новый Apps Script deployment для этого обновления не создаётся.

Для следующих изменений сначала читать текущие файлы этих каталогов и этот документ.
Архивы старых обновлений служат историей, а не основанием для замены нового исходника.
Правки из обоих чатов вносить в эти же рабочие файлы. ChatGPT-чаты не имеют автоматической
общей памяти и совместной блокировки файлов; этот документ не объединяет чаты в интерфейсе.
Не утверждать, что неизвестные сообщения второго чата или его более новые правки прочитаны.
В текущей сессии поиск чата «Подключение VS Code tg new» не сработал.
Сверены доступные пакеты V13.8, V13.9.1 и предыдущие исправления Git commit.

После успешной установки установщик создаёт `current-project` внутри выведенной папки
Campus1-backups: frontend, backend и PROJECT_STATE.json с коммитом, действующим deployment
и контрольными суммами файлов. Этот снимок отражает файлы на ПК после установки,
включая сохранившиеся локальные изменения. Снимок остаётся локальным и автоматически не публикуется.
До запуска установщика включённые в архив модули — подготовленное обновление,
а не подтверждённый полный текущий исходник с ПК пользователя.

Сохраняемые требования:

- ИИ удалён из Mini App; вместо него задачи, проекты, потоки, шаблоны и календарь.
- Создание задач, делегирование, сроки, статусы и протокол из V13.9 сохраняются.
- Техническая панель — только существующему владельцу по OWNER_ID и разработчику 7272434463.
- Технические работы включаются и выключаются вручную. Все остальные, включая администрацию,
  блокируются интерфейсом и сервером; после выключения приложение открывается автоматически.
- Должности: председатель, заместитель председателя, глава и заместитель главы сектора,
  обычный участник и активист. Секторы: СДК, SMM, ОПМ, САН (Санитарный сектор).
- Назначать должности могут администрация с manage_students, владелец и разработчик.
- Должность учитывается отдельно от доступа. Владелец по умолчанию — Глава СДК.
- Комнаты: 13, 14, 23, затем 30–162, кроме 118, 126 и 127.
- Студенты, документы, поиск, комнаты, темы и сезоны предыдущих версий сохраняются.
- Обновление Apps Script выполняется через clasp в C:\tg в реальный существующий deployment
  текущего проекта, не @HEAD. Интерфейс публикуется из существующего Git-репозитория.

Исправление V13.10.1 относится к установщику: резервирование до синхронизации,
сохранение и возврат локальных изменений, команды без shell:true, сохранение текущего
AppTasks.gs и общий снимок проекта. Функции приложения остаются V13.10.
