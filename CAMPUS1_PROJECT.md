# Campus №1 — единый проект

Актуальная версия после установки: V13.11 Unified Recovery.

Рабочие каталоги:
- `C:\tg` — Telegram-бот + Google Apps Script API.
- `C:\campus1-miniapp` — GitHub frontend + безопасная копия backend-модулей.

Правила проекта:
- ИИ полностью отключён от Mini App и API. Не возвращать его, пока владелец сам не попросит.
- Нижняя вкладка: `Задачи`, а не ИИ.
- Задачи: Задачи / Проекты / Потоки / Шаблоны / Календарь.
- Председатель и заместитель председателя могут ставить задачи главам секторов.
- Глава сектора может делегировать подчинённому своего сектора.
- Если исполнитель не выбран, задача остаётся за главой.
- Глава всегда остаётся главным ответственным после делегирования.
- Срок хранится вместе с задачей.
- Telegram ID разработчика: `7272434463`.
- Специальная панель сверху доступна только OWNER_ID и разработчику.
- Технические работы вручную включают/выключают только OWNER_ID и разработчик.
- При технических работах блокируются все остальные, включая администрацию и активистов.
- После выключения клиенты автоматически проверяют статус и возвращаются в приложение.
- Должности: Председатель, Заместитель председателя, Глава сектора,
  Заместитель главы сектора, Участник, Активист.
- Секторы: СДК, SMM, ОПМ, САН.
- Должности не заменяют уровень доступа.
- Выдавать должности могут администрация с `manage_students`, OWNER_ID и разработчик.
- OWNER_ID по умолчанию отображается как `Глава СДК`, но сохраняет права владельца.
- Сезоны, документы, комнаты, студенты, поиск, журнал и аналитика сохраняются.
- Кнопка смены сезонов сверху остаётся только у OWNER_ID.
- Комнаты: 13, 14, 23, 30–117, 119–125, 128–162.
- Действующий Apps Script deployment обновляется, новый проект не создаётся.
- Webhook не менять без отдельной причины.
